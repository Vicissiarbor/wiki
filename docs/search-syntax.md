# 搜索语法

一个搜索框，三种匹配方式，靠输入语法切换，没有模式下拉框。搜索不受界面语言影响：
中英文字段都会被匹配（英文界面下搜「复数」能找到 `Complex Number`）。

## 三种写法

| 写法 | 举例 | 命中 |
| --- | --- | --- |
| 直接输入（默认） | `熵` | 名称、别名、标签、简介、正文里含「熵」的词条 |
| `=名字` | `=熵`、`=Complex Number` | 名称或别名完全等于它（忽略大小写、全半角、首尾空格） |
| `/表达式/flags` | `/^熵\|热力学/`、`/^ent/i` | 按正则匹配名称、别名、标签、简介（正文需显式限定） |

## 字段限定

`字段:内容`，可用 `name:`、`alias:`、`tag:`、`summary:`、`content:`、`text:`（全字段）；
`aliases:`/`tags:`/`description:`/`body:`/`all:` 是等价的别名写法。

```
tag:物理                 标签里含「物理」
content:/H\(X\)/         正文里匹配正则
text:熵                  所有字段一起搜
```

## 结果

按相关度排序：名称精确 > 名称前缀 > 别名精确 > 名称包含 > 别名包含 > 标签 > 简介 > 正文；
同分时短名称优先。命中的字用 `<mark>` 高亮，超过 1000 条会截断。

## 正则限制

浏览器里的正则无法中断，所以有几条硬限制：

- 查询最长 200 字符；单条正文参与匹配时最多取前 4096 字符；整轮搜索 400 ms 预算，超时返回部分结果。
- 拒绝 `(a+)+`、`(a|a)+`、`.*.*x` 这类会指数级回溯的写法，提示改写（如 `(a+)+` → `a+`）。
- 不支持 `g` / `y` 标志；不写 flags 时默认加 `i`。

## 地址与快捷键

| 地址 | 含义 |
| --- | --- |
| `#/` | 完整索引 |
| `#/?q=熵` | 一次搜索，可直接分享 |
| `#/e/complexNumber` | 某个词条 |

`/` 或 `Ctrl`/`⌘+K` 聚焦搜索框，`Enter` 打开第一条结果，`Esc` 清空（词条页上则返回索引）。
