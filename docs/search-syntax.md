# 搜索语法

一个搜索框，三种匹配方式，靠输入语法切换——界面上没有模式下拉框。

**搜索不看界面语言**：中文和英文字段都会被匹配，所以在英文界面下输入 `复数` 能找到
`Complex Number`，在中文界面下输入 `=Complex Number` 也照样命中。界面语言只决定"显示哪一套字段"。

## 一览

| 写法 | 模式 | 举例 | 命中 |
| --- | --- | --- | --- |
| 直接输入 | 包含（默认） | `熵` | 名称、别名、标签、简介、**正文**里包含「熵」的词条（中英字段都算） |
| `=名字` | 精确 | `=熵`、`=信息熵` | 名称或别名**完全等于**「熵」（忽略大小写、全半角、首尾空格） |
| `/表达式/` 或 `/表达式/flags` | 正则 | `/^熵\|热力学/`、`/^ent/i` | 名称、别名、标签、简介按正则匹配（正文需显式限定） |
| `字段:内容` | 字段限定 | `tag:物理`、`content:/H\(X\)/` | 只在该字段内匹配 |

语法标记优先于默认模式：写了 `=` 就是精确，写了 `/…/` 就是正则。

## 字段限定

| 前缀 | 字段 | 可用别名 |
| --- | --- | --- |
| `name:` | 名称 | — |
| `alias:` | 别名 | `aliases:` |
| `tag:` | 标签 | `tags:` |
| `summary:` | 简介 | `description:` |
| `content:` | 正文 | `body:` |
| `text:` | 全部字段（含正文） | `all:` |

```
tag:物理                 只找标签里含「物理」的词条
content:/H\(X\)/         正文里匹配正则 H(X)
text:熵                  名称、别名、标签、简介、正文全找
name:=熵                 名称完全等于「熵」
```

字段限定后面必须跟内容：只输入 `tag:` 会提示「请在 “tag” 后输入要查找的内容」。

## 结果排序与高亮

- 相关度：名称精确（1000）> 名称前缀（800）> 别名精确（700）> 名称包含（600）> 别名包含（420）> 标签（220–320）> 简介（140–200）> 正文（90–120）；
- 同分时短名称优先，再按 A–Z 索引的顺序（中文按拼音）；
- 命中的文字用 `<mark>` 高亮；
- 显示「命中 N 条」，超过 1000 条会截断并提示缩小范围；
- 搜索时不再显示字母标题（结果是按相关度排的，分组反而碍事）；清空输入即回到按首字母分组的完整索引。

## 正则的边界（重要）

浏览器里的正则**无法被中断**：一旦触发灾难性回溯，整个页面会卡死。因此有四重防护：

1. **查询长度上限** 200 字符；
2. **输入截断**：单条正文最多取前 4096 字符参与正则匹配；
3. **回溯形状拦截**：以下写法会被直接拒绝并解释原因——`(a+)+`、`(a*)*`、`(a|a)+`、`(\w+\s?)*` 这类「分组内已有量词、分组外再叠加量词」或「对含 `|` 的分组做量词」，以及 `.*.*x` 这类「连续通配」；
4. **时间预算** 400 ms：每 16 条检查一次，超时则返回部分结果并提示。

被拒绝时的提示形如：

> 该正则表达式可能导致灾难性回溯（嵌套量词（如 (a+)+）），已拒绝执行。请改写表达式，例如把 (a+)+ 改成 a+。

安全改写的常见做法：

| 想写 | 别写 | 改写为 |
| --- | --- | --- |
| 一串 a 后面跟 b | `(a+)+b` | `a+b` |
| 字母或数字重复 | `([a-z0-9]+)+` | `[a-z0-9]+` |
| 任意内容里找 needle | `.*.*needle` | `needle`（包含模式已经做子串匹配） |
| 两个词任一出现 | `(熵\|焓)+` | `熵\|焓` |

其他限制：不支持 `g` / `y` 标志（会让 `test()` 依赖上次匹配位置）；未写 flags 时默认加 `i`（忽略大小写）。

## 地址栏与分享

搜索和词条都会写进地址栏，可以直接发给手机：

| 地址 | 含义 |
| --- | --- |
| `#/` | 完整索引 |
| `#/?q=熵` | 一次搜索 |
| `#/?q=tag%3A物理` | 标签筛选 |
| `#/e/entropy` | 某个词条页 |

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `/` 或 `Ctrl`/`⌘` + `K` | 聚焦搜索框 |
| `Enter` | 打开第一条结果 |
| `Esc` | 输入框有内容时清空；在词条页时返回索引 |
| `清空` 按钮 | 清空输入并回到完整索引 |

## 快速示例

```
熵                    包含匹配，正文里提到「熵」的词条也会出现
=熵                   只要名称/别名正好是「熵」的那一条
=entropy              别名精确匹配
/^焓|^熵$/            名称以「焓」或「熵」开头
tag:物理              物理标签
content:/H\(X\)/      正文里匹配正则
text:/正则*/          任意字段里的「正则」
"信息 熵"             精确模式下可用引号包住带空格的名字
```
