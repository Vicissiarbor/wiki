# 搜索语法

三种匹配方式 + 可选的字段限定。写法可以混用，语法标记的优先级高于界面上的模式选择。

## 一览

| 写法 | 模式 | 举例 | 命中 |
| --- | --- | --- | --- |
| 直接输入 | 包含（默认） | `熵` | 名称、别名、标签、简介、**正文**里包含「熵」的词条 |
| `=名字` | 精确 | `=熵`、`=信息熵` | 名称或别名**完全等于**「熵」（忽略大小写、全半角、首尾空格） |
| `/表达式/` 或 `/表达式/flags` | 正则 | `/^熵\|热力学/`、`/^ent/i` | 名称、别名、标签、简介按正则匹配（正文需显式限定） |
| `字段:内容` | 字段限定 | `tag:物理`、`content:/H\(X\)/` | 只在该字段内匹配 |

界面上还有一个「包含 / 精确 / 正则」下拉框，决定**没有语法标记时**用哪种模式。输入 `=` 或 `/…/` 会临时覆盖下拉框的选择。

## 字段限定

| 前缀 | 字段 | 可用别名 |
| --- | --- | --- |
| `name:` | 名称 | — |
| `alias:` | 别名 | `aliases:` |
| `tag:` | 标签 | `tags:` |
| `summary:` | 简介 | `description:` |
| `content:` | 正文 | `body:` |
| `text:` | 全部字段（含正文） | `all:` |

例：

```
tag:物理                 只找标签里含「物理」的词条
content:/H\(X\)/         正文里匹配正则 H(X)
text:熵                  名称、别名、标签、简介、正文全找
name:=熵                 名称完全等于「熵」
```

字段限定后面必须跟内容，`tag:` 单独输入会提示「请在 “tag” 后输入要查找的内容」。

## 排序与高亮

- 结果按相关度排序：名称精确命中（1000）> 名称前缀（800）> 名称包含（600）> 别名精确（700）…… 正文命中（90–120）；
- 同分时短名称优先，再按 A–Z 索引的顺序；
- 命中的文字在列表里用 `<mark>` 高亮；
- 结果显示「命中 N 条，显示 M 条」，超过 1000 条会截断。

## 正则的边界（重要）

浏览器里的正则**无法被中断**：一旦触发灾难性回溯，整个页面会卡死。因此本站做了四重防护：

1. **查询长度上限** 200 字符；
2. **输入截断**：单条正文最多取前 4096 字符参与正则匹配；
3. **回溯形状拦截**：以下写法会被直接拒绝并给出解释 —— `(a+)+`、`(a*)*`、`(a|a)+`、`(\w+\s?)*` 这类「分组内已有量词、分组外再叠加量词」或「对含 `|` 的分组做量词」以及 `.*.*x` 这类「连续通配」；
4. **时间预算** 400 ms：每 16 条检查一次，超时返回部分结果并提示。

被拒绝时的提示形如：

> 该正则表达式可能导致灾难性回溯（嵌套量词（如 (a+)+）），已拒绝执行。请改写表达式，例如把 (a+)+ 改成 a+。

安全改写的常见做法：

| 想写 | 别写 | 改写为 |
| --- | --- | --- |
| 一串 a 后面跟 b | `(a+)+b` | `a+b` |
| 字母或数字重复 | `([a-z0-9]+)+` | `[a-z0-9]+` |
| 任意内容里找 needle | `.*.*needle` | `needle`（包含模式已经做子串匹配） |
| 两个词任一出现 | `(熵|焓)+` | `熵|焓` |

其他限制：不支持 `g` / `y` 标志（会被拒绝，因为会让 `test()` 的行为依赖上次匹配位置）；未写 flags 时默认加 `i`（忽略大小写）。

## 其它

- **空查询 = 浏览模式**：显示全部词条，按首字母分组（中文按拼音），并显示 A–Z 索引条；
- **首字母筛选与查询可以叠加**：先点 `S`，再输入 `=熵`，只在 S 组里找；
- **`[[词条名]]`**：正文里可以引用别的词条；点击即跳转（走的是 `#/?e=<id>` 深链）；
- 查询会写进地址栏（`#/?q=…&mode=…&letter=…&e=…`），可以直接把链接发给手机。

## 快速示例

```
熵                    包含匹配，正文里提到「熵」的也会出现
=熵                   只要名称/别名正好是「熵」的那一条
=entropy              别名精确匹配
/^焓|^熵$/            名称以「焓」或「熵」开头
tag:物理              物理标签
content:/H\(X\)/      正文里匹配正则
text:/正则*/          任意字段里的「正则」
"信息 熵"             引号内的空格会保留（精确模式下常用于含空格的名字）
```
